## 3. 怎么选

研究报告先看 `GPT Researcher` 与 `DeerFlow`；教学应用看 `DeepTutor`；办公产物看 `GenOffice`。金融类项目只作为工作流与多角色协作案例，本专题没有验证其预测或收益表现。

## 4. 带着一个任务读源码

挑选一个与你的博客相关的流程：发现资料 → 保存来源 → 归类 → 生成草稿 → 人工验收。阅读项目如何表示中间结果、处理失败和回溯来源，比直接照搬整套产品更有价值。
