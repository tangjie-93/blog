# 11. AI 学习路线与实战任务

## 目标

8 周后能独立完成一个带引用的知识库问答系统、一个受限工具 Agent，并能解释模型、数据、评估和安全取舍。每天至少留下代码、笔记、评测结果或复述中的一种证据。

## 8 周计划

| 周 | 主题 | 交付物 |
|---|---|---|
| 1 | 数学、概率、机器学习 | 分类器、混淆矩阵、错误分析 |
| 2 | PyTorch 与深度学习 | 训练循环和验证报告 |
| 3 | Transformer 与 tokenizer | attention 可视化、token 成本表 |
| 4 | LLM 使用与结构化输出 | 抽取 API、schema 校验 |
| 5 | 数据工程、Embedding、RAG | 本地 RAG 和 20 条题集 |
| 6 | Agent、工具、状态 | 只读 Agent、最大步数和审计 |
| 7 | 多模态、部署、成本 | 一个图片/PDF 处理实验和压测 |
| 8 | 评估、安全、演示 | 回归报告、风险清单、最终演示 |

## 最小项目

**项目：企业制度助手。** 输入脱敏 Markdown、PDF 或图片制度；输出带引用的答案、无证据拒答和版本提示。加入一个只读查询工具，禁止写数据库。记录 query、候选、引用、模型版本、索引版本、耗时和 token。

验收问题：

- 正确证据排在 top-k 之外时，你如何定位？
- 用户无权访问某文档时，过滤发生在哪一步？
- 制度更新后，旧引用和缓存如何失效？
- 文档内容包含“忽略系统提示”时，Agent 如何处理？

## 学习方法

每周做一次费曼复述：不用术语解释本周主题；再做一次反例练习：说明它什么时候不适用。读 GitHub 源码时先找入口、数据流、配置和测试，再深入优化实现。
