# `AI` 知识图谱与学习路线

这套文档回答三个问题：`AI` 包括哪些知识、这些知识如何连接、如何用 `GitHub` 项目把知识变成能力。它面向有编程基础的工程师，重点是可解释、可运行和可评估。

## 1、总图

```text
数学与统计
  └─ 机器学习 → 深度学习 → Transformer
                    ├─ 语言模型 → LLM 应用 → RAG / Agent
                    ├─ 视觉模型 → 多模态 / 生成模型
                    └─ 语音模型 → ASR / TTS / 实时交互
数据工程 ───────────┘
训练与微调 → 推理部署 → 评估、安全、治理 → 产品工程
```

## 3、最小主干

先学 `Python`、线性代数、概率和数据处理，再用 `PyTorch` 完成一个分类器；随后理解 `Transformer`，调用开源模型完成结构化抽取；最后做一个带引用的 `RAG` 和一个受限 `Agent`。不要一开始同时学习所有模型、框架和云服务。

## 4、阅读规则

每个主题都回答：输入是什么、输出是什么、训练或检索目标是什么、失败时如何观测、生产环境的边界是什么。`GitHub` 项目状态、stars 和许可证均为 `2026-10-17` 检索快照，使用前重新查看仓库主页和发布说明。
