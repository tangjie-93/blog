## 6.1 缓存（第1-5天）

### 6.1.1 Redis概述

Redis（Remote Dictionary Server）是一个基于内存的高性能键值存储数据库，广泛用于缓存、消息队列、分布式锁等场景。

**与前端概念对比：**

| 前端概念 | Redis |
|---------|-------|
| localStorage / sessionStorage | Redis缓存 |
| IndexedDB | Redis持久化存储 |
| Vuex / Pinia 状态管理 | Redis集中式缓存 |
| Service Worker缓存 | Redis CDN缓存 |
| WebSocket实时通信 | Redis Pub/Sub消息 |

### 6.1.3 Redis数据结构与使用场景

```java
@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(
            RedisConnectionFactory connectionFactory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);

        // 使用Jackson2JsonRedisSerializer作为值的序列化器
        Jackson2JsonRedisSerializer<Object> jsonSerializer =
            new Jackson2JsonRedisSerializer<>(Object.class);
        ObjectMapper mapper = new ObjectMapper();
        mapper.setVisibility(PropertyAccessor.ALL, JsonAutoDetect.Visibility.ANY);
        mapper.activateDefaultTyping(
            mapper.getPolymorphicTypeValidator(),
            ObjectMapper.DefaultTyping.NON_FINAL
        );
        jsonSerializer.setObjectMapper(mapper);

        // 使用StringRedisSerializer作为key的序列化器
        StringRedisSerializer stringSerializer = new StringRedisSerializer();

        // key使用String序列化
        template.setKeySerializer(stringSerializer);
        template.setHashKeySerializer(stringSerializer);

        // value使用JSON序列化
        template.setValueSerializer(jsonSerializer);
        template.setHashValueSerializer(jsonSerializer);

        template.afterPropertiesSet();
        return template;
    }
}
```

#### 实际业务示例：用户缓存
```java
@Service
public class UserCacheService {

    @Autowired
    private UserMapper userMapper;

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    private static final String USER_KEY_PREFIX = "user:";
    private static final long USER_CACHE_TTL = 30; // 分钟

    /**
     * 查询用户（先查缓存，缓存没有再查数据库）
     */
    public User getUserById(Long id) {
        String key = USER_KEY_PREFIX + id;

        // 1. 先查缓存
        User user = (User) redisTemplate.opsForValue().get(key);
        if (user != null) {
            return user;
        }

        // 2. 缓存没有，查数据库
        user = userMapper.selectById(id);
        if (user != null) {
            // 3. 写入缓存，设置过期时间
            redisTemplate.opsForValue().set(key, user, USER_CACHE_TTL, TimeUnit.MINUTES);
        }

        return user;
    }

    /**
     * 更新用户（同时更新缓存）
     */
    public void updateUser(User user) {
        String key = USER_KEY_PREFIX + user.getId();
        userMapper.updateById(user);
        // 更新缓存
        redisTemplate.opsForValue().set(key, user, USER_CACHE_TTL, TimeUnit.MINUTES);
    }

    /**
     * 删除用户（同时删除缓存）
     */
    public void deleteUser(Long id) {
        String key = USER_KEY_PREFIX + id;
        userMapper.deleteById(id);
        redisTemplate.delete(key);
    }
}
```

### 6.1.5 缓存穿透、击穿、雪崩

#### 缓存穿透（Cache Penetration）

**问题描述：** 查询一个不存在的数据，缓存中没有，每次请求都会打到数据库。就像子弹穿透了缓存一样。

**前端类比：** 就像前端请求一个不存在的API，缓存和CDN都没有命中，每次都打到后端。

**解决方案：**

```java
@Service
public class CachePenetrationSolution {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Autowired
    private UserMapper userMapper;

    /**
     * 方案1：缓存空值（简单但不够优雅）
     */
    public User getUserById_CacheNull(Long id) {
        String key = "user:" + id;
        Object cached = redisTemplate.opsForValue().get(key);

        // 如果缓存的是空值标记，直接返回null
        if ("NULL".equals(cached)) {
            return null;
        }

        if (cached != null) {
            return (User) cached;
        }

        User user = userMapper.selectById(id);
        if (user == null) {
            // 缓存空值，设置较短的过期时间
            redisTemplate.opsForValue().set(key, "NULL", 5, TimeUnit.MINUTES);
            return null;
        }

        redisTemplate.opsForValue().set(key, user, 30, TimeUnit.MINUTES);
        return user;
    }

    /**
     * 方案2：布隆过滤器（推荐，高效）
     * 在缓存之前加一层布隆过滤器，快速判断数据是否存在
     */
    @Component
    public class BloomFilterManager {
        // 使用Redis的Bitmap实现布隆过滤器
        // 或者使用Google Guava的BloomFilter
        private BloomFilter<Long> bloomFilter;

        @PostConstruct
        public void init() {
            // 创建布隆过滤器
            // 预期元素数量10000，误判率0.01
            bloomFilter = BloomFilter.create(
                Funnels.longFunnel(), 10000, 0.01);

            // 加载所有用户ID到布隆过滤器
            loadUserIds();
        }

        private void loadUserIds() {
            // 从数据库加载所有用户ID
            // bloomFilter.put(userId);
        }

        public boolean mightContain(Long id) {
            return bloomFilter.mightContain(id);
        }
    }

    public User getUserById_BloomFilter(Long id) {
        // 1. 先查布隆过滤器
        if (!bloomFilterManager.mightContain(id)) {
            return null; // 一定不存在
        }

        // 2. 布隆过滤器说可能存在，再查缓存
        String key = "user:" + id;
        User user = (User) redisTemplate.opsForValue().get(key);
        if (user != null) {
            return user;
        }

        // 3. 查数据库
        user = userMapper.selectById(id);
        if (user != null) {
            redisTemplate.opsForValue().set(key, user, 30, TimeUnit.MINUTES);
        }

        return user;
    }
}
```

#### 缓存击穿（Cache Breakdown）

**问题描述：** 一个热点key在过期的瞬间，大量并发请求同时打到数据库。

**前端类比：** 就像前端某个热门数据缓存失效，瞬间大量请求同时发起，导致后端压力骤增。

**解决方案：**

```java
@Service
public class CacheBreakdownSolution {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Autowired
    private ProductMapper productMapper;

    /**
     * 方案1：互斥锁（分布式锁）
     * 只允许一个线程查询数据库，其他线程等待
     */
    public Product getProductById_Mutex(Long id) {
        String key = "product:" + id;
        Product product = (Product) redisTemplate.opsForValue().get(key);

        if (product != null) {
            return product;
        }

        // 尝试获取分布式锁
        String lockKey = "lock:product:" + id;
        String lockValue = UUID.randomUUID().toString();

        try {
            // 加锁，设置过期时间防止死锁
            Boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, lockValue, 10, TimeUnit.SECONDS);

            if (Boolean.TRUE.equals(locked)) {
                // 获取锁成功，查询数据库
                product = productMapper.selectById(id);
                if (product != null) {
                    redisTemplate.opsForValue().set(key, product, 30, TimeUnit.MINUTES);
                }
            } else {
                // 获取锁失败，休眠后重试
                Thread.sleep(50);
                return getProductById_Mutex(id); // 递归重试
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            // 释放锁（只释放自己的锁）
            Object currentLockValue = redisTemplate.opsForValue().get(lockKey);
            if (lockValue.equals(currentLockValue)) {
                redisTemplate.delete(lockKey);
            }
        }

        return product;
    }

    /**
     * 方案2：逻辑过期（推荐）
     * 不设置Redis过期时间，在value中存储逻辑过期时间
     */
    public Product getProductById_LogicalExpire(Long id) {
        String key = "product:" + id;
        Map<String, Object> cached = (Map<String, Object>) redisTemplate.opsForValue().get(key);

        if (cached == null) {
            // 缓存不存在，直接查数据库并重建缓存
            return rebuildCache(id);
        }

        Product product = (Product) cached.get("product");
        Long expireTime = (Long) cached.get("expireTime");

        if (System.currentTimeMillis() < expireTime) {
            // 未过期，直接返回
            return product;
        }

        // 已过期，开启异步线程重建缓存
        String lockKey = "lock:product:" + id;
        String lockValue = UUID.randomUUID().toString();
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, lockValue, 10, TimeUnit.SECONDS);

        if (Boolean.TRUE.equals(locked)) {
            // 获取锁成功，异步重建缓存
            CompletableFuture.runAsync(() -> {
                try {
                    rebuildCache(id);
                } finally {
                    redisTemplate.delete(lockKey);
                }
            });
        }

        // 返回旧数据（保证可用性）
        return product;
    }

    private Product rebuildCache(Long id) {
        Product product = productMapper.selectById(id);
        if (product != null) {
            String key = "product:" + id;
            Map<String, Object> cacheMap = new HashMap<>();
            cacheMap.put("product", product);
            cacheMap.put("expireTime", System.currentTimeMillis() + 30 * 60 * 1000L);
            redisTemplate.opsForValue().set(key, cacheMap);
        }
        return product;
    }
}
```

#### 缓存雪崩（Cache Avalanche）

**问题描述：** 大量缓存key在同一时间过期，导致大量请求同时打到数据库。

**前端类比：** 就像前端多个页面的缓存同时失效，瞬间所有请求都打到后端。

**解决方案：**

```java
@Service
public class CacheAvalancheSolution {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    /**
     * 方案1：过期时间加随机值
     * 避免大量key同时过期
     */
    public void setWithRandomExpire(String key, Object value) {
        // 基础过期时间30分钟 + 随机0-5分钟
        long baseTime = 30;
        long randomTime = ThreadLocalRandom.current().nextLong(0, 5);
        redisTemplate.opsForValue().set(key, value, baseTime + randomTime, TimeUnit.MINUTES);
    }

    /**
     * 方案2：多级缓存
     * 本地缓存 + Redis缓存 + 数据库
     */
    @Component
    public class MultiLevelCache {

        // 本地缓存（Caffeine）
        private final Cache<String, Object> localCache = Caffeine.newBuilder()
            .maximumSize(1000)
            .expireAfterWrite(5, TimeUnit.MINUTES)
            .build();

        @Autowired
        private RedisTemplate<String, Object> redisTemplate;

        public Object get(String key) {
            // 1. 查本地缓存
            Object value = localCache.getIfPresent(key);
            if (value != null) {
                return value;
            }

            // 2. 查Redis缓存
            value = redisTemplate.opsForValue().get(key);
            if (value != null) {
                localCache.put(key, value); // 回填本地缓存
                return value;
            }

            // 3. 查数据库（由调用方处理）
            return null;
        }

        public void put(String key, Object value) {
            localCache.put(key, value);
            redisTemplate.opsForValue().set(key, value, 30, TimeUnit.MINUTES);
        }
    }

    /**
     * 方案3：服务降级与限流
     */
    @Component
    public class CacheFallbackHandler {

        // 当缓存和数据库都不可用时，返回默认值
        public <T> T getOrDefault(String key, T defaultValue, Supplier<T> dbQuery) {
            try {
                T result = dbQuery.get();
                return result != null ? result : defaultValue;
            } catch (Exception e) {
                // 数据库查询失败，返回默认值
                return defaultValue;
            }
        }
    }
}
```

#### 分布式锁使用示例
```java
@Service
public class DistributedLockService {

    @Autowired
    private RedissonClient redissonClient;

    /**
     * 基本分布式锁
     */
    public void basicLock() {
        RLock lock = redissonClient.getLock("myLock");
        try {
            // 加锁（阻塞等待）
            lock.lock();

            // 执行业务逻辑
            doBusiness();

        } finally {
            // 释放锁
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    /**
     * 带超时的分布式锁
     */
    public void lockWithTimeout() {
        RLock lock = redissonClient.getLock("myLock");
        try {
            // 尝试加锁，等待3秒，锁定后10秒自动释放
            boolean acquired = lock.tryLock(3, 10, TimeUnit.SECONDS);
            if (acquired) {
                doBusiness();
            } else {
                // 获取锁失败
                System.out.println("获取锁失败");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    /**
     * 公平锁（按请求顺序获取锁）
     */
    public void fairLock() {
        RLock fairLock = redissonClient.getFairLock("myFairLock");
        try {
            fairLock.lock();
            doBusiness();
        } finally {
            if (fairLock.isHeldByCurrentThread()) {
                fairLock.unlock();
            }
        }
    }

    /**
     * 读写锁（读读不互斥，读写互斥）
     */
    public void readWriteLock() {
        RReadWriteLock rwLock = redissonClient.getReadWriteLock("myRWLock");

        // 读锁
        RLock readLock = rwLock.readLock();
        readLock.lock();
        try {
            // 读操作
            readData();
        } finally {
            readLock.unlock();
        }

        // 写锁
        RLock writeLock = rwLock.writeLock();
        writeLock.lock();
        try {
            // 写操作
            writeData();
        } finally {
            writeLock.unlock();
        }
    }

    /**
     * 联锁（同时锁定多个锁）
     */
    public void multiLock() {
        RLock lock1 = redissonClient.getLock("lock1");
        RLock lock2 = redissonClient.getLock("lock2");
        RLock lock3 = redissonClient.getLock("lock3");

        RLock multiLock = redissonClient.getMultiLock(lock1, lock2, lock3);
        try {
            multiLock.lock();
            doBusiness();
        } finally {
            multiLock.unlock();
        }
    }

    /**
     * 红锁（RedLock，跨多个Redis实例）
     */
    public void redLock() {
        RLock lock1 = redissonClient.getLock("lock1");
        RLock lock2 = redissonClient.getLock("lock2");
        RLock lock3 = redissonClient.getLock("lock3");

        RedissonRedLock redLock = new RedissonRedLock(lock1, lock2, lock3);
        try {
            // 只要有一个实例加锁成功即可
            redLock.lock();
            doBusiness();
        } finally {
            redLock.unlock();
        }
    }

    /**
     * 实际业务场景：库存扣减
     */
    public boolean deductStock(Long productId, int quantity) {
        String lockKey = "stock:lock:" + productId;
        RLock lock = redissonClient.getLock(lockKey);

        try {
            boolean acquired = lock.tryLock(3, TimeUnit.SECONDS);
            if (!acquired) {
                return false;
            }

            // 查询库存
            String stockKey = "stock:" + productId;
            int stock = (int) redissonClient.getBucket(stockKey).get();

            if (stock >= quantity) {
                // 扣减库存
                redissonClient.getBucket(stockKey).set(stock - quantity);
                return true;
            }
            return false;

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return false;
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    private void doBusiness() {
        // 业务逻辑
    }

    private void readData() {
        // 读操作
    }

    private void writeData() {
        // 写操作
    }
}
```

#### 使用注解实现分布式锁
```java
// 自定义注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface DistributedLock {
    String key();
    long waitTime() default 3;
    long leaseTime() default 10;
    TimeUnit timeUnit() default TimeUnit.SECONDS;
}

// AOP切面
@Aspect
@Component
public class DistributedLockAspect {

    @Autowired
    private RedissonClient redissonClient;

    @Around("@annotation(distributedLock)")
    public Object around(ProceedingJoinPoint joinPoint,
                         DistributedLock distributedLock) throws Throwable {
        String lockKey = "lock:" + distributedLock.key();
        RLock lock = redissonClient.getLock(lockKey);

        try {
            boolean acquired = lock.tryLock(
                distributedLock.waitTime(),
                distributedLock.leaseTime(),
                distributedLock.timeUnit()
            );

            if (!acquired) {
                throw new RuntimeException("获取分布式锁失败: " + lockKey);
            }

            return joinPoint.proceed();
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}

@Service
public class OrderService {

    @DistributedLock(key = "'order:' + #orderId", waitTime = 5)
    public void processOrder(Long orderId) {
        // 处理订单
```

### 6.2.1 Elasticsearch概述

Elasticsearch（ES）是一个基于Lucene的分布式全文搜索引擎，提供近实时的搜索和分析功能。

**与前端概念对比：**

| 前端概念 | Elasticsearch |
|---------|--------------|
| 浏览器Ctrl+F搜索 | ES全文检索 |
| 前端本地搜索（如表格筛选） | ES服务端搜索 |
| 前端分页 | ES分页查询 |
| 前端排序 | ES排序与聚合 |
| 前端模糊匹配 | ES模糊查询 |

**Elasticsearch vs MySQL：**

| 对比项 | MySQL | Elasticsearch |
|-------|-------|--------------|
| 数据存储 | 行存储 | 倒排索引 |
| 查询方式 | SQL精确查询 | 全文检索 + 精确查询 |
| 事务支持 | 支持ACID | 不支持事务 |
| 实时性 | 实时写入 | 近实时（1秒延迟） |
| 适用场景 | 核心业务数据 | 搜索、日志分析 |
| 数据一致性 | 强一致 | 最终一致 |

### 6.2.2 倒排索引原理

#### 正排索引（Forward Index）
```
文档ID → 文档内容
doc1 → "Java编程入门"
doc2 → "Python数据分析"
doc3 → "Java与Python对比"
```

#### 倒排索引（Inverted Index）
```
词条 → 包含该词条的文档ID列表
Java    → [doc1, doc3]
Python  → [doc2, doc3]
编程    → [doc1]
入门    → [doc1]
数据分析 → [doc2]
对比    → [doc3]
```

**倒排索引结构：**
```
Term（词条）
├── Term Dictionary（词条字典，有序）
├── Term Index（词条索引，FST结构，加速查找）
└── Posting List（倒排列表，文档ID + 词频 + 位置）
```

#### 数据同步（MySQL → Elasticsearch）
```java
@Service
public class DataSyncService {

    @Autowired
    private ProductMapper productMapper;

    @Autowired
    private ElasticsearchRestTemplate elasticsearchRestTemplate;

    /**
     * 全量同步
     */
    public void fullSync() {
        int page = 0;
        int size = 500;

        while (true) {
            Page<Product> productPage = productMapper.selectPage(
                new Page<>(page, size), null);

            List<ProductDocument> documents = productPage.getRecords().stream()
                .map(this::convertToDocument)
                .collect(Collectors.toList());

            if (documents.isEmpty()) break;

            elasticsearchRestTemplate.save(documents);
            page++;

            if (!productPage.hasNext()) break;
        }
    }

    /**
     * 增量同步（基于更新时间）
     */
    public void incrementalSync(LocalDateTime lastSyncTime) {
        List<Product> products = productMapper.selectList(
            new QueryWrapper<Product>()
                .ge("updated_at", lastSyncTime)
        );

        List<ProductDocument> documents = products.stream()
            .map(this::convertToDocument)
            .collect(Collectors.toList());

        elasticsearchRestTemplate.save(documents);
    }

    private ProductDocument convertToDocument(Product product) {
        ProductDocument doc = new ProductDocument();
        doc.setId(product.getId());
        doc.setName(product.getName());
        doc.setDescription(product.getDescription());
        doc.setPrice(product.getPrice());
        doc.setCategory(product.getCategory());
        doc.setBrand(product.getBrand());
        doc.setStatus(product.getStatus());
        doc.setCreatedAt(product.getCreatedAt());
        return doc;
    }
}
```

#### 自定义追踪
```java
@Service
public class TracedService {

    /**
     * 使用注解追踪方法
     */
    @Trace
    public void processOrder(Order order) {
        // 方法会被自动追踪
    }

    /**
     * 自定义标签
     */
    @Tag(key = "orderId", value = "arg[0].id")
    @Tag(key = "amount", value = "arg[0].amount")
    public void createOrder(Order order) {
        // 自定义标签会附加到Span上
    }

    /**
     * 自定义Span
     */
    public void complexBusiness() {
        try (Scope scope = ContextManager.createLocalSpan("complexBusiness")) {
            // 业务逻辑
            step1();
            step2();
            step3();
        }
    }

    /**
     * 自定义上下文传播
     */
    public void crossServiceCall() {
        ContextCarrier carrier = new ContextCarrier();
        AbstractSpan span = ContextManager.createExitSpan("remoteCall", carrier, "remote-service:8080");

        try {
            // 传递上下文到远程服务
            // carrier.serialize() 可以放入HTTP Header
            remoteCall();
        } finally {
            ContextManager.stopSpan();
        }
    }
}
```
