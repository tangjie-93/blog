## 3. 怎么选

从前端转入时，先比较 `AI SDK` 与 `Mastra`；需要显式状态、暂停恢复时再比较 `LangGraph`。主表中的 `langgraph` 是 `Python` 仓库，不能把它的星数当成 `JavaScript` 版本的星数。

[`AutoGen` 官方说明](https://github.com/microsoft/autogen#readme)已声明停止维护并建议迁移到 `Microsoft Agent Framework`，即使归档字段暂未同步，也不应把它列为活跃的新项目首选。[`Swarm` 官方说明](https://github.com/openai/swarm#readme)则明确它是教学实验并已有 `Agents SDK` 替代。

## 4. 带着一个任务读源码

同一个“读取文章并生成带来源的摘要”任务，分别记录模型调用、工具调用、状态变化和停止条件。只有在单 `Agent` 无法清晰承担职责时，再拆分多个角色。
