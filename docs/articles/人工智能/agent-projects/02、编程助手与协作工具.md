## 3. 怎么选

先从已经使用的终端或编辑器里选一种工具。不要同时配置所有助手；用同一个小修复比较改动范围、测试结果、执行记录与人工审查成本。

[`Claude Code` 的仓库许可](https://github.com/anthropics/claude-code/blob/main/LICENSE.md)指向厂商商业条款，不能因为仓库公开就将整个产品称为开源。`Roo Code` 已归档，保留用于阅读历史实现。

## 4. 带着一个任务读源码

拿博客中的一个可重复问题建立基线：提供复现步骤，要求只修改相关文件并运行原有检查。对照工具输出与真实 `diff`，观察失败后如何继续，而不只看一次演示能否成功。
