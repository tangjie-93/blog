## 3. 怎么选

知识问答与工作流原型先比较 `Dify`、`Langflow`；跨业务系统自动化看 `n8n`、`Activepieces`；个人任务可比较 `OpenClaw`、`Hermes Agent` 和 `nanobot`。这是按用途给出的试用顺序，不是性能排名。

`Flowise` 与 `AgentGPT` 的仓库已归档，表中保留是为了识别旧资料中的项目，不作为本轮新部署的优先选项。`n8n` 自述采用 `fair-code`；公开仓库与无限制商业授权不能画等号。

## 4. 带着一个任务读源码

先做一个只读任务：读取指定资料，整理待办并返回来源。再逐步增加持久状态和写操作。试用时记录需要哪些服务、模型费用、部署步骤和人工介入点。
