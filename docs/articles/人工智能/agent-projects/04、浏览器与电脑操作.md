## 1. 这一类解决什么问题

浏览器 `Agent` 根据目标决定步骤；浏览器 `CLI`、`SDK` 与 `MCP` 服务提供具体操作。它们可能组合使用，不能把“暴露一个点击工具”当成完整的任务规划系统。

## 3. 怎么选

已有编程 `Agent` 时，先比较 `agent-browser`、`Playwright MCP`、`Chrome DevTools MCP`；自己开发网页任务服务时，再比较 `Browser Use` 与 `Stagehand`。页面内嵌助手可研究 `page-agent`。

## 4. 带着一个任务读源码

在自己的测试页面完成“搜索文章 → 打开结果 → 提取标题与链接”。比较定位是否稳定、失败是否能重试、过程是否可复现。电脑操作项目还需要额外验证操作系统及隔离环境。
