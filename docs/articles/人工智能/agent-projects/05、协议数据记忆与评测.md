## 3. 怎么选

工具接入看 `MCP`；跨 `Agent` 协作看 `A2A`；文档处理看 `MinerU`、`RAGFlow`；记忆看 `Mem0`、`Letta`；执行环境看 `E2B`、`OpenSandbox`；追踪与回归看 `Langfuse`、`Phoenix`、`Promptfoo`。

`Daytona` 此仓库已归档；这里记录的是仓库状态，不推断其商业服务是否停止。`FastMCP` 的规范仓库地址已是 `PrefectHQ/fastmcp`，旧的 `jlowin/fastmcp` 不重复计数。

## 4. 带着一个任务读源码

保存一条完整任务轨迹：输入、检索证据、模型调用、工具结果和最终验收。对错误来源做分类后再选组件。`MCP` 解决接口连接，不自动解决权限、业务正确性或任务验收。
