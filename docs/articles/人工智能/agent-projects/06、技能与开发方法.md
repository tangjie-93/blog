## 1. 这一类解决什么问题

技能库、角色库和工程方法需要由支持它们的宿主加载。它们的价值是把任务流程表达清楚，不是安装后凭空获得新的模型能力。不要把 `Markdown` 角色数量当成同时运行的 `Agent` 数量。

## 3. 怎么选

先读官方 `anthropics/skills`，理解一个技能的触发条件、输入和产出；再按实际任务选一套工程或设计技能。`Superpowers` 与 `Ponytail` 等方法侧重点不同，应先检查它们对已有工作方式的影响。

## 4. 带着一个任务读源码

把“补一篇博客文章并验证本地链接”做成一个可重复任务。比较启用技能前后是否减少遗漏，是否增加不必要步骤。一次只引入一项方法，保留失败样例。
