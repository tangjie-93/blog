## 3. 怎么选

中文基础可先看 `hello-agents`；想理解编程 `Agent` 的循环可看 `learn-claude-code`；再从 `GenAI_Agents` 或 `awesome-llm-apps` 中选一个最小示例。目录只在遇到明确需求时查阅。

## 4. 带着一个任务读源码

读完一个示例后合上源码，用自己的话画出输入、状态、工具与退出条件，再独立改一个约束。能解释与修改，比收藏更多仓库更能检验是否学会。
