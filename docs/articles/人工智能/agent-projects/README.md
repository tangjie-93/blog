## 2. 前端开发者的第一轮阅读

不要同时安装全部项目。下面是按学习成本和任务衔接给出的编辑建议，不是跑分结论：

1. **先理解循环**：从 [`hello-agents`](https://github.com/datawhalechina/hello-agents)（⭐ `86,366`） 或 [`learn-claude-code`](https://github.com/shareAI-lab/learn-claude-code)（⭐ `80,025`） 选一个，理解“模型决定行动 → 工具返回结果 → 继续或停止”。
2. **跑通 `Web` 产品**：比较 [`AI SDK`](https://github.com/vercel/ai)（⭐ `27,805`） 与 [`Mastra`](https://github.com/mastra-ai/mastra)（⭐ `29,400`），选一个实现带工具调用的文章助手。
3. **解决真实任务**：用 [`agent-browser`](https://github.com/vercel-labs/agent-browser)（⭐ `46,944`） 或 [`Stagehand`](https://github.com/browserbase/stagehand)（⭐ `25,979`） 研究页面操作；如果任务仅需读仓库元数据，直接调用 `GitHub API` 更简单。
4. **需要长流程时再加编排**：研究 [`LangGraph`](https://github.com/langchain-ai/langgraph)（⭐ `44,631`） 的状态和恢复；需要 `TypeScript` 时查看对应语言仓库，不混用两边的安装方式或星数。
5. **保存失败证据**：用任务记录建立基线，规模增加后再评估 [`Langfuse`](https://github.com/langfuse/langfuse)（⭐ `37,138`） 或 [`Promptfoo`](https://github.com/promptfoo/promptfoo)（⭐ `26,945`）。

完整的比较方法、源码阅读问题及一个适合本站的练习见[选型与源码阅读](./09、选型与源码阅读.md)。需要原理时可回到本站 [Agent 架构专题](../agent/)与 [LangChain 专题](../langchain/)。

## 3. 看榜单前要分清的几层

| 层次 | 提供什么 | 不能直接推导什么 |
| --- | --- | --- |
| 成品应用 | 可操作的助手或工作台 | 不代表内部框架可以直接抽出来复用 |
| 框架与运行时 | 组织模型、工具、状态和任务 | 不代表已经有适合你的产品界面 |
| 协议与工具 | 连接外部能力，执行具体动作 | 不代表能自主规划并验收任务 |
| 技能与角色 | 任务说明、流程、资源和脚本 | 不代表一个可独立运行的 `Agent` |
| 教程与目录 | 解释概念、给出样例、发现项目 | 不代表每个链接都经过运行验证 |

`Stars` 反映累计关注度。真正选型还要比较任务效果、维护状态、部署条件、许可证、运行成本和失败后的恢复方式。
