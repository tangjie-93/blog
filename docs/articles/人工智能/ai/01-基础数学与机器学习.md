# 01. 基础数学与机器学习

## 1. 模型到底在学什么

预测工单处理时长时，人提供特征 `x` 和真实时长 `y`，模型调整参数以减小误差。**学到的是数据中的规律，不保证是业务中真正可用的规律。**

<AiVisual title="一个样本怎样推动参数变化？" kind="flow" :nodes="[
  { label: '预测', detail: '用当前参数算出 ŷ，而不是直接读取答案。' },
  { label: '损失', detail: '比较 ŷ 与标签 y，定义错得多远。' },
  { label: '梯度', detail: '求损失对每个参数的局部变化率。' },
  { label: '更新', detail: '沿负梯度走一小步，再重新预测。' }
]" caption="单样本梯度下降示意；损失、数据与学习率不合适时，不保证每步变好。" />

参数 `w、b` 由训练学习；学习率、步数等**超参数**由实验者配置；特征、标签及来源属于**数据**。三者不要混为“模型配置”。

## 2. 用数字看懂一次更新

<AiConcept mode="training" />

取 `ŷ=wx+b`，损失 `L=(ŷ−y)²/2`。当 `x=2、y=4、w=1、b=0` 时：

| 阶段 | 结果 |
| --- | --- |
| 前向计算 | `ŷ=2，L=2` |
| 梯度 | `∂L/∂w=(ŷ−y)x=−4，∂L/∂b=−2` |
| 用学习率 `η=0.1` 同时更新 | `w=1.4，b=0.2` |
| 重新计算 | `ŷ=3，L=0.5` |

**梯度决定局部方向，学习率决定步幅。** 同一样本若用 `η=1`，新损失反而变成 `32`；负梯度不是全局最优导航。

::: details 展开手算与反向传播
两个参数必须使用同一次前向计算得到的梯度，不能先更新 w，再用新 w 计算 b 的梯度。

```text
w_new = 1 − 0.1×(−4) = 1.4
b_new = 0 − 0.1×(−2) = 0.2
ŷ_new = 1.4×2 + 0.2 = 3
L_new = (3−4)²/2 = 0.5

若 η=1：w_new=5，b_new=2，ŷ_new=12，L_new=32
```

反向传播沿计算图应用链式法则：`x → z → a → L` 时，`dL/dx=(dL/da)(da/dz)(dz/dx)`。自动微分替你求导，不替你确认标签、损失和数据切分正确。

没有非线性激活的多层线性变换仍能合并为一层；ReLU、GELU 等使网络能表达更丰富的函数。
:::

## 3. 向量、概率：后面章节的两把尺子

| 工具 | 必要公式 | 使用边界 |
| --- | --- | --- |
| 矩阵乘法 | `[n,d] @ [d,k] → [n,k]` | 内侧维度必须一致；先给轴命名 |
| 余弦相似度 | `cos(a,b)=(a·b)/(‖a‖₂‖b‖₂)` | 零向量无定义；相似不等于事实正确 |
| 交叉熵 | `CE(p,q)=−Σpᵢ ln qᵢ` | one-hot 标签下是正确类别的负对数概率 |

交叉熵提供连续训练信号：正确类别概率为 `0.51` 和 `0.99` 时，都算预测正确，但损失分别约 `0.673`、`0.010`。**模型给出 0.9，不自动意味着真实正确率为 90%。**

::: details 展开矩阵手算、数值稳定与优化手段
```text
x = [1, 2]
W = [[0.2, −0.1], [0.5, 0.3]]
b = [0.1, 0.2]
xW+b = [1×0.2+2×0.5+0.1, 1×(−0.1)+2×0.3+0.2]
     = [1.3, 0.7]

相似度对照：
a=[1,0]，b=[2,0] → 内积=2，余弦=1
a=[1,0]，c=[0,1] → 内积=0，余弦=0
```

只有经过训练、把相关性编码进方向的表示，余弦才可能对应语义相似。标准化可改善不同特征尺度造成的优化困难，但均值、方差只能在训练集拟合。PCA 保留高方差方向，不保证保留业务信息。

正确类别概率为 `0.01` 时，交叉熵约 `4.605`；实现通常用 logits 与稳定的 log-softmax，避免直接计算 `ln(0)`。熵 `H(p)=−Σpᵢlnpᵢ` 衡量分布不确定性，低熵也可能是确信地错了；可信程度需要独立的校准与事实核验。

| 手段 | 改变什么 | 不会替你解决什么 |
| --- | --- | --- |
| Mini-batch SGD | 用部分样本估计梯度 | 每步损失未必下降 |
| Adam | 用梯度一阶、二阶统计调整更新 | 不会自动选对学习率和目标 |
| L2 / 权重衰减 | 约束参数规模，具体实现有区别 | 不能修复标签错误与泄漏 |
| Dropout | 训练时随机屏蔽部分激活 | 不能代替所有数据增强 |
| 早停 | 按验证表现选择停止点 | 不能反复看测试集来决定何时停 |
:::

## 4. 泛化：会做练习，不等于会做新题

<AiVisual title="三份数据各自允许做什么？" kind="compare" :nodes="[
  { label: '训练集', detail: '拟合预处理并更新参数。' },
  { label: '验证集', detail: '选择超参数、阈值与停止点。' },
  { label: '测试集', detail: '方案冻结后估计未参与选择的数据表现。' }
]" caption="这是职责对比，不是固定比例；切分单位应匹配新文档、新客户或未来请求等目标。" />

把同一制度的相邻 chunk 随机分到两侧，可能只测到“认出熟悉文本”。面对新文档应按文档族切分，面对未来请求应按时间切分，并检查近重复与预测时点可得性。**用测试结果指导修改后，它事实上已成验证集。**

RAG 检索测试题所需资料本身不是泄漏；用隐藏答案、同源重复或测试反馈调优，再声称独立评测，才是问题。

## 5. 指标：95% 准确率也可能一条风险都没找出

100 条请求只有 5 条需人工处理，全部预测“不需要”就有 95% 准确率，却是零召回。若预测 8 条、其中 4 条正确：

```text
TP=4，FP=4，FN=1，TN=91
Precision=4/8=0.50，Recall=4/5=0.80，Accuracy=95%
```

漏掉风险与增加人工量，哪个代价更高？这决定阈值。回归可看 MAE/RMSE，检索看 Recall@k/MRR，生成看任务成功与事实支持；比较前先核对分母。

## 6. 动手验证与排错

下载 <a :href="withBase('/ai-examples/foundations.py')" download>foundations.py</a>，或在仓库根目录运行：

```bash
python3 docs/public/ai-examples/foundations.py
python3 docs/public/ai-examples/foundations.py --test
```

标准库实验应复现 `w=1.4、b=0.2、L=0.5`，并在无噪声 `y=3x+1` 上拟合参数。 **这是机制演示，五个简单点不是泛化评测。** 完整说明见 [基础实验包](./examples/)。

::: details 失败诊断、练习与答案
| 现象 | 优先检查 |
| --- | --- |
| 训练与验证都差 | 小样本标签、特征，能否先过拟合一小批正确数据 |
| 训练好、验证差 | 过拟合、近重复、分组切分与分布差异 |
| 离线好、线上差 | 时间泄漏、漂移、预处理版本不一致 |
| 损失骤增或非有限 | 学习率、输入范围、梯度范数、首个异常步骤 |

- **入门**：重算 `η=0.1`，解释为什么 w 增大；再试 `0.00001` 和较大值，比较相同步数下的误差。
- **进阶**：实现标准库逻辑回归，报告混淆矩阵；改变阈值观察指标变化。
- **工程**：交付按文档族切分的方案、去重规则、数据版本和评测报告。

**训练损失越低越好吗？** 不一定：可能记住样本、利用泄漏或优化了错误目标。加入噪声后也不要断言损失必须为零。

**为什么不能全量标准化？** 测试数据会参与拟合。先切分，只在训练集 fit；交叉验证的每个训练折也要独立拟合。
:::
