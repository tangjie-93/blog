# 02. 深度学习与 Transformer

## 1. 为什么单个词向量不够

“我把苹果放进包里”和“苹果发布了新品”中的“苹果”，词面相同，指向却不同。静态查表给同一个 token 相同的初始向量；模型需要根据其他位置的信息更新它，形成**上下文相关表示**。

注意力提供一种可学习的通信机制：每个位置提出查询，根据与其他位置的匹配程度汇总内容。它不是数据库精确查找，也不意味着模型真的像人一样把注意力集中在某处。

学习目标：追踪一个 `[B,T,D]` 张量怎样经过模型；手算一个注意力输出；解释为什么训练时不能偷看未来。

## 2. 先认清模型的数据流

<AiConcept mode="transformer" />

对团队知识助手输入“住宿上限是多少”，模型并不是直接读取“上限”字段。文本先被切为 token，再映射为向量，经多个 block 变换，最后形成下一 token 的词表分数。

| 符号 | 含义 | 教学设定 |
| --- | --- | --- |
| B | batch size | 2 条序列 |
| T | 序列长度 | 每条 4 个 token |
| D | 隐藏维度 | 8 |
| H | 注意力头数 | 2 |
| Dh | 每头维度 D/H | 4 |
| Vocab | 词表大小 | 与隐藏维度不同 |

```text
token IDs          [2,4]
查表后的 X          [2,4,8]
Q、K、V（拆头）     [2,2,4,4]
注意力分数          [2,2,4,4]   最后两维：查询位置 × 被读取位置
各头加权结果        [2,2,4,4]
拼头并输出投影      [2,4,8]
最终词表 logits     [2,4,Vocab]
```

不要因为 T 和 Dh 恰好都是 4，就以为这些轴可以交换。调试时应给轴命名，而不仅打印数字。

## 3. Q、K、V 到底是什么

对于单个头，用输入 X 乘三个不同的可学习矩阵：

```text
Q = XWq     查询：当前位置需要什么信息
K = XWk     匹配线索：其他位置怎样被找到
V = XWv     内容：匹配后要汇总什么
S = QKᵀ / √Dh
A = softmax(S + mask)   沿被读取位置归一化
Y = AV
```

Q、K、V 都是向量，不是自然语言问题、关键词标签和数据库值。类比只帮助理解角色，不能用来推断每个维度的含义。

### 3.1 为什么要除以 √Dh

在各维分量近似独立、均值零且方差相近的假设下，点积的方差随维度增长。分数过大时，softmax 可能过于尖锐，梯度变小。缩放有助于维持合适数值范围，不是随意让结果落到 0–1。

### 3.2 手算一次注意力

采用已经投影好的 Q、K、V，省略 batch 与多头：

```text
Q = K = [[1,0], [0,1]]
V = [[10,0], [0,20]]
Dh = 2
```

第一个查询的分数为 `[1/√2, 0] ≈ [0.7071, 0]`。softmax：

```text
权重 = [exp(0.7071)/(exp(0.7071)+1), 1/(exp(0.7071)+1)]
     ≈ [0.6698, 0.3302]
输出 = 0.6698×[10,0] + 0.3302×[0,20]
     ≈ [6.6976, 6.6048]
```

这不是“选中第一个词”，而是把两个 value 加权汇总。权重之和为 1，但**权重不是原文正确概率，也不是因果解释**。

## 4. Causal Mask：训练时为什么必须遮住答案

假设输入为 `[今天, 天气, 很, 好]`，位置“天气”的隐藏状态用于预测“很”。如果它能直接读取未来的“很”，训练就出现捷径。

因果遮罩在 softmax **之前**加入分数矩阵：

```text
       位置0  位置1  位置2
位置0    0    −∞    −∞
位置1    0     0    −∞
位置2    0     0     0
```

`exp(−∞)=0`，未来位置不会贡献内容。上面的两位置算例加上 mask 后，第一行只能看到自己，权重变为 `[1,0]`，输出就是 `[10,0]`。

**可验证不变量：**任意改变未来位置的 V，都不应改变更早位置的输出。这个测试比仅仅看到训练损失下降更能证明 mask 生效。

另有两种常被混淆的 mask：

- **Padding attention mask：**阻止真实 token 读取无意义的填充位置。
- **Loss mask：**决定哪些位置参与训练损失，例如忽略 padding 或只监督助手回答。

它们的目的和施加位置不同，不能只配一个 mask 就假定全部处理好了。

## 5. 多头、MLP、残差：各解决什么问题

### 5.1 多头不是把同一结果重复算几遍

常规多头注意力把投影后的特征重排为 H 个子空间，每个头独立计算，再拼接并做输出投影。不同头可能形成不同的关系模式，但不能保证某头专管语法、某头专管指代。

GQA/MQA 让多个查询头共享较少的 K/V 头，降低 KV Cache 开销；因此“Q/K/V 的头数永远相同”不是现代模型的普遍事实。前面的 shape 表限定为常规 MHA。

### 5.2 注意力与前馈网络的分工

- 注意力让不同位置**交换信息**。
- MLP 在每个位置使用同一组参数，**非线性变换特征**。
- 残差把变换结果加回输入，使信息与梯度有更直接的路径。
- LayerNorm/RMSNorm 调节数值尺度，具体公式和放置位置依架构而异。

典型 Pre-Norm block 可写成：

```text
h = x + Attention(Norm(x))
y = h + MLP(Norm(h))
```

原始 Transformer 使用另一种归一化布局；现代模型还会采用门控 MLP、RMSNorm 等。`Linear(D,4D) → GELU → Linear(4D,D)` 是一种常见教学实例，不是所有模型的定义。

## 6. 没有位置，模型怎么知道顺序

无位置编码的 self-attention 对输入的排列具有相应的置换等变性质：如果重排输入，输出也相应重排，不能仅凭内容感知原本顺序。因果 mask 提供了部分结构约束，但不能替代合适的位置方案。

| 方案 | 位置进入计算的方式 | 需要警惕 |
| --- | --- | --- |
| 绝对位置 | 将位置表示加到输入 | 训练范围外的位置是否可靠 |
| RoPE | 对 Q/K 按位置旋转 | 长度外推需要模型与缩放策略支持 |
| ALiBi | 在注意力分数加入距离偏置 | 是特定设计，不是通用可插拔补丁 |

位置方案有相对距离结构，不等于“把窗口改大就能可靠理解更长内容”。要同时检查训练长度、推理实现和任务表现。

## 7. 二次方成本：说清楚是哪一部分

标准密集注意力的分数矩阵包含 `B×H×T²` 个元素。例如 `B=1，H=8，T=4096`，FP16 显式分数矩阵需要：

```text
1×8×4096²×2 bytes = 268,435,456 bytes = 256 MiB
T 翻倍到 8192 → 1 GiB
```

这是**一份显式分数矩阵的教学预算**，不是模型总显存。梯度、激活、权重、优化器和其他中间结果还要额外占用。

FlashAttention 等实现通过分块和重计算避免将整份矩阵存入高带宽显存，因此不能说所有实现的实际显存都按这个算式增长；密集注意力计算量中的二次项仍需区分。

解码时使用 KV Cache，不必重新计算所有旧位置的 K/V，但新 query 仍要读取过去的 key/value。长上下文会增加缓存和带宽压力，见 [08 部署](./08-训练微调与推理部署.md)。

## 8. 三类架构与训练目标

| 架构 | 通常如何看上下文 | 代表性用途 |
| --- | --- | --- |
| Encoder-only | 双向读取输入 | 表征、分类、检索 |
| Decoder-only | 因果读取已有序列 | 自回归文本与代码生成 |
| Encoder-Decoder | 编码端双向，解码端因果并读编码结果 | 条件生成、翻译、语音任务 |

这是结构分类，不是能力等级。数据、训练目标、规模与后训练都影响表现。

对因果语言模型，训练样本需要错开一位：

```text
完整序列：[A, B, C, D]
输入：    [A, B, C]
目标：    [B, C, D]
```

训练时通常用真实前文预测后续 token（teacher forcing）；推理时前文包含模型自己的输出。早期错误可能影响后续生成，低训练损失不能保证长序列任务正确。

## 9. 动手实验与验证方式

[标准库实验包](./examples/)提供单头 self-attention，不需要安装 PyTorch：

```bash
python3 docs/public/ai-examples/foundations.py
python3 docs/public/ai-examples/foundations.py --test
```

阅读 `attention()`，依次检查：

1. 点积缩放是否除以 `√Dh`，而不是序列长度。
2. softmax 是否沿 key 位置计算，每行和是否为 1。
3. 因果模式下第一行是否恰为 `[1,0]`。
4. 修改第二个 V 后，第一个输出是否保持不变。

它只处理单批次、单头、等长 self-attention，不包含 padding、dropout、训练与 GPU 内核，不是生产实现。

进入 PyTorch 时，先用同样的 Q/K/V 对照标准库输出，再引入批次与多头。创建 mask 时确保与输入在同一 device；使用框架 attention API 时查清布尔 mask 的 True 究竟表示“允许”还是“遮住”，不同 API 约定可能不同。

## 10. 练习、反例与答案

**入门：**手算未遮罩的第一行输出，再解释加 mask 后为什么变成 `[10,0]`。

**进阶：**将 `B=2，T=16，D=32，H=4` 写入 shape 表。改变 T 后，哪些维度增长，哪些参数数量不变？

**工程：**对同一长文，把关键证据放开头、中间、结尾，比较问答质量；不要用“窗口足够大”当成“证据必然可用”。

::: details 自测：两层线性层为什么还不够？
如果中间没有非线性，(xW₁+b₁)W₂+b₂ 可合并为 xW'+b'，表达能力仍是仿射变换。增加层数本身不保证增加有效非线性表达。
:::

::: details 自测：注意力权重 0.9 能说明原文很可信吗？
不能。它表示当前头、当前位置对 value 的混合权重，不是事实真实性、证据支持度或最终输出的完整归因。
:::

::: details 自测：序列翻倍，所有成本都四倍吗？
不是。密集注意力分数矩阵的元素数四倍；MLP 等按位置计算的部分通常线性增长，真实显存还受内核实现、缓存和训练策略影响。
:::
