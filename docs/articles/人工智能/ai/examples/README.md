# AI 基础实验包

## 1. 运行条件

Python 3.10 或更新版本；无第三方依赖、联网请求、模型下载或 API Key。文件为本站维护的教学代码，不需要执行任何外部安装脚本。

下载 <a :href="withBase('/ai-examples/foundations.py')" download>foundations.py</a>，在保存目录运行：

```bash
python3 foundations.py
python3 foundations.py --test
```

在本仓库根目录则运行：

```bash
python3 docs/public/ai-examples/foundations.py
python3 docs/public/ai-examples/foundations.py --test
```

## 3. 预期结果与断言

- 单步：`w=1.4，b=0.2，新损失=0.5`。
- 无噪声回归：w 接近 3，b 接近 1；这是人工构造的简单函数。
- 无 mask 第一行权重约 `[0.6698,0.3302]`，输出约 `[6.6976,6.6048]`。
- 因果 mask 第一行权重为 `[1,0]`，输出 `[10,0]`。
- 概率 `[0.6,0.3,0.1]`、top-p=0.8 时，保留 ID 0、1，重归一化为约 `[0.6667,0.3333]`。
- 测试模式包含 5 个测试方法，覆盖数值结果、非法温度、阈值边界、收敛与 mask 不变量。

固定随机种子有助于同环境重现采样，但测试不依赖某个具体随机输出序列。浮点结果以容差比较，不要求所有平台逐位相同。

## 4. 做一次真正的反例练习

1. 把 top-p 的判断放到追加候选前，观察 0.8 阈值测试是否失败。
2. 去掉 causal 截断，观察“改变未来值”测试是否失败。
3. 把回归学习率设得很小，比较相同步数误差，不要只比较运行是否成功。
4. 给 attention 加入形状不一致输入，确认明确报错，而不是被 zip 静默截断。

脚本刻意不模拟完整 tokenizer、预训练、RAG 或真实 Agent。后续 04–09 每章有独立标准库小实验或真实实验协议；[RAG 最小实现](../../rag/03-最小实现.md)用于继续学习整条问答链路。
