# 定价与单位经济模型：把价值、成本和现金流算清楚

上一篇：[海外收款与支付状态机](./04-海外收款与支付状态机.md) · 下一篇：[首批用户与发布渠道实验](./06-首批用户与发布渠道实验.md)

价格不是把单次计算费用乘一个倍数。客户购买的是可采用的结果，你承担的是交付、售后和持续履约。本文用“客户反馈整理器”建立教学账本，不涉及模型接口实现。**除标明出处的平台公开报价外，金额、人数、用量和比例全部是假设，不是市场数据、真实试验或收益预测。**

> **视频跟练**：[`YC` 的企业产品定价课](https://www.youtube.com/watch?v=4hjiRmgmHiU)讲价值、成本与报价判断，不是支付界面教程。看后写一份含限制与退款规则的套餐说明，并亲手重算本文基准和压力场景；[练习及视频核验程度](./10-视频跟练与项目实操路线.md#_5-报价与首客-看方法课-做真实记录)见跟练页。

## 1. 从价值证据选收费单位

1. 请目标客户展示最近一次整理流程，记录从导入到人工审核、导出的总时间，而非只问“愿意付多少钱”。
2. 确认谁使用、谁审批预算，以及任务多久发生一次。用获授权样本比较结果，保留用户指出的遗漏和返工，不编造节省工时。
3. 选客户能理解、系统能核验的收费单位，并写清上限。成本底线决定能否持续交付，客户价值决定是否值得购买，两者不能相互替代。

本例先定义一次处理为“一个符合行数和单条长度限制的反馈文件，生成可追溯主题并允许导出”。重复点击不重复扣量；系统失败释放额度，客户主动提交新文件则另计。不要按主题条数收费，否则系统拆分方式会影响账单，用户也难预测成本。

价值定价是一种判断方法，不是另一种扣款周期。若客户认为价值来自可靠交付和来源追溯，可据此讨论价格；但不能把尚未证明的“节省两小时”写成保证。也不要直接按客户工资推定其愿付价格，还要考虑审核时间、替代工具和采购摩擦。

| 收费方式 | 适配条件 | 本例应加的限制 |
| --- | --- | --- |
| 一次性额度包 | 任务偶发，用户不想持续订阅 | 次数、输入上限、有效期及失败处理 |
| 固定月订阅 | 团队持续整理，愿为稳定可用付费 | 每期额度、重置时间、取消与降级规则 |
| 按量或基础费加超额 | 用量可测，客户接受波动账单 | 预算提醒、硬上限、超额须明确授权 |
| 按席位 | 协作人数确实驱动价值 | 第一版没有协作能力就不要硬套 |

`Stripe Billing` 当前文档区分固定价、按席位、阶梯和按量，按量还包含基础费加超额、随用随付及预付额度消耗。它解释收费结构，并不能证明其中某种结构适合你的客户。[来源一](#来源一)

## 2. 先写套餐承诺，再做报价试验

教学方案：月付 `$29`，每期 `30` 次处理，额度不结转，不自动超额扣款。大文件先拒绝并提示拆分，而不是后台无限重试。先验证这一个方案，不同时推出一排没有证据的套餐。

按以下顺序执行：先把限制写成客户可读说明；在沙箱核对购买、消耗、失败返还与期末取消；向已沟通的目标用户展示同一范围和价格；记录报价、付款、实际采用、退款与下次任务。没有正式准入就不收费，也不把口头称赞算付费验证。

若有人嫌贵，先问其当前替代方式和不愿购买的具体原因。低频用户可能需要额度包，结果不可用则应先改质量；这两种问题都不一定靠降价解决。变更价格要记录版本和适用对象，旧订阅按已有承诺及适用规则处理，不能无通知修改。

可复制的套餐说明模板：

```text
适用对象／具体任务：
价格、币种、含税或另计税／扣费周期：
一次处理的定义／文件、行数、文本长度上限：
每期额度／重置时区／是否结转／有效期：
失败、重试、重复提交怎样计量：
超额是否停止／加购或授权方式：
取消生效日／退款入口／人工支持边界：
价格版本／适用客户／复核日期：
```

## 3. 建立完整的客户月账本

单位经济回答“多服务一个客户，会多留下多少资源”，不是只看收入减计算费。先统一收入和费用口径：买家代缴的间接税不计产品收入；所得税另估；年费现金到账、按期收入与平台结算分别记录，不能混成同一个余额。

截至检索日，`Paddle` 公开标准价格为每笔结账 `5% + $0.50`，页面提示低于 `$10` 的产品可咨询定制价格。合同、税费和结算条件仍需另核对，下面仅为演算采用该费率，不声称你的账单一定如此。[来源二](#来源二)

以下按一个客户完整用完当月额度计算，币种均为美元；假设 `$29` 为不含间接税的产品收入，演算手续费基数也是 `$29`。实际含税收款或计费基数不同，必须替换后重算。

| 项目 | 教学假设与算式 | 客户月金额 |
| --- | --- | --- |
| 产品收入 | `$29` | `$29.00` |
| 支付平台费 | `$29 × 5% + $0.50` | `$1.95` |
| 处理成本，含重试 | `30 × 1.2` 次平均尝试 `× $0.04` | `$1.44` |
| 随客户增加的存储与交付 | 每客户月分摊 | `$1.00` |
| 客服与人工审核 | `6 ÷ 60` 小时 `× $20` | `$2.00` |
| 退款及争议损失准备 | `$29 × 5%`，不假设原手续费退回 | `$1.45` |
| 汇兑及结算费准备 | `$29 × 1%` | `$0.29` |
| 合计直接成本 | `1.95 + 1.44 + 1 + 2 + 1.45 + 0.29` | `$8.13` |
| 获客前客户月贡献 | `29 - 8.13` | `$20.87` |

这里的退款准备是预算损失，月末要用实际退款及争议费用替换，**不能既减退款收入又再扣同一笔准备**。人工虽未对外付款，也按机会成本计入；获客沟通工时另计到获客成本，不在客服中重复计算。

设当月有 `100` 个完整月付客户，其中 `20` 个为当月新增，完全成本获客费用为每人 `$30`，固定托管、工具、会计及维护工时合计 `$300`。费用分桶必须互斥：随用量变化的资源在表内，基础订阅与公共维护在固定项。

```text
客户月贡献率 = 20.87 ÷ 29 = 71.97%
月度经常性收入 MRR = 100 × 29 = 2900
当月获客费用 = 20 × 30 = 600
所得税前经营结余 = 100 × 20.87 - 600 - 300 = 1187
若仅为预算演练，暂留正结余的 10% = 118.70
预留后余额 = 1187 - 118.70 = 1068.30
```

最后两行只是税费敏感性假设，**不是适用税率或应纳税额**，税基、抵扣及申报要另算。这个结余也不是银行可提现金额：退款时点、结算门槛和账期仍会影响现金。若获客全部发生在交付前，还应单列前期垫资预算。

## 4. 用压力场景找亏损边界

保持售价和次数不变，把长输入单次尝试成本调到 `$0.30`，平均尝试数调到 `2`，客服调为 `20` 分钟，退款争议准备调至收入的 `10%`，其余不变：

```text
处理成本 = 30 × 2 × 0.30 = 18
人工成本 = 20 ÷ 60 × 20 = 6.6667
客户月贡献 = 29 - 1.95 - 18 - 1 - 6.6667 - 2.90 - 0.29
           = -1.8067，约 -1.81
```

同一价格在压力下已经连直接交付都覆盖不了，增加客户会扩大亏损。先缩小输入、限制重试与并发，再考虑加购、调整价格或暂停高成本任务；预算告警不是硬停止。

再做一个独立的含税场景：假设售价 `$29` 内含 `20%` 间接税，税前收入为 `29 ÷ 1.2 = 24.1667`。为单独观察税影响，暂把基准直接成本固定在 `$8.13`，贡献降至约 `$16.04`。这不是平台实际费率模型，但能揭示把含税售价全算收入的错误。

现金压力也要单测：新客户需预付获客费用而平台尚未结算，仍必须支付交付成本。即使账面贡献为正，也可能因退款集中发生或回款延后而缺钱，应设现金投入上限与停止条件。

## 5. 不把订阅指标当利润

`MRR` 是归一到月的经常性收入，不扣交付、获客和人工，不等于利润；一次性额度包也不能为了好看塞进 `MRR`。年付收入应按服务月份归一，而非把整笔现金当作当月经常性收入。[来源三](#来源三)

`CAC` 应包括渠道费、销售工具和获客工时，再除以同期归因一致的新增付费客户。`Paddle` 的指标资料强调完全成本及毛利调整；不要用营业收入直接推导“已经回本”。[来源四](#来源四)

本例用贡献口径粗估回收期：`30 ÷ 20.87 ≈ 1.44` 个月，尚未分摊固定成本与所得税，且假设客户持续付费、成本不变，所以不是回本承诺。初期留存样本短，不用一次观察倒推出可靠的 `LTV`；先看同批客户在下一任务周期是否复用。

“终身无限”则把一次收入换成长久且无上限的义务，未来重试、人工、存储涨价都由你承担。若销售一次性产品，应明确可交付范围、支持期限及维护边界，不能靠用户“不太会用”维持账面盈利。

## 6. 复盘模板与验收清单

每个账期先填实际账本，再决定改价，不追求漂亮比例。

```text
账期／价格版本／客户批次：
不含间接税收入／退款调整／MRR：
成功处理数／总尝试数／高成本样本：
平台费／交付资源／汇兑结算费：
客服审核工时／获客工时与渠道费：
固定费用与公共维护工时／税费预估依据：
直接贡献／获客后结余／银行实际回款：
下一周期复用／退款原因／需修改的限制：
本轮现金上限／停止条件／复核日期：
```

- [ ] 客户可准确复述价格、额度、有效期、取消与超额规则。
- [ ] 计算包含失败重试、退款争议、人工、获客、汇兑和税费。
- [ ] 按表可复算，准备金与实际损失不重复扣除。
- [ ] 基准、长输入、含税及延迟回款场景分别检查。
- [ ] 经常性收入、经营结余与银行现金分别展示，不承诺收益。
- [ ] 尚无真实采用或复用证据时，结论标为待验证，不宣称找到市场。
