# 算法学习工作区

## 1. 目标与起点

目标：从阅读题解逐渐过渡到独立建模、实现、验证与解释。默认已有 `JavaScript` 编程基础，算法熟练度待第一周实际练习确认。

节奏：每周 `4` 次，每次 `30～45` 分钟。使用熟悉的语言；先用 `JavaScript`，不要让类型配置或新语言分散精力。

最终证据：能独立完成有代表性的基础题，逐步尝试中等题；每个主题有闭卷重写、边界测试和一次迁移。题量不作为唯一目标。

## 2. 今天从哪里开始

先打开[第一天任务](./daily/day-01.md)，完成最大值扫描并保留运行结果。再按[第一周安排](./weekly/week-01.md)继续。

完整知识路线见[算法学习路线](../../docs/articles/算法/算法学习路线.md)，旧文入口见[算法地图](../../docs/articles/算法/README.md)。本目录用于本地学习记录，不参与博客构建。

## 3. 使用顺序

1. 查看[阶段里程碑](./roadmap.md)和本周计划。
2. 在 `demos/` 写练习，运行断言，将结果放进当天记录。
3. 在[笔记索引](./notes/index.md)记录关键发现和失败用例。
4. 更新[进度](./progress.md)，每周填写[复盘](./reviews/week-01-review.md)。

十六周具体任务均已写入 `weekly/`，每周含四次安排和验收；第二周起直接在周文件末尾复盘。每日记录仍从第一天开始，后续根据实际学习增加，避免预填完成记录。
