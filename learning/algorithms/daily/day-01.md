# 第一天：一次扫描能解决什么

## 1. 今日目标

在 `30～45` 分钟内独立完成一个小题，知道自己卡在理解、实现还是验证。

实现 `maxValue(nums)`：输入为有限数值组成的数组，返回最大值；空数组返回 `null`；不改变输入。题目约定元素均为有限数值，不要求在本练习中校验其他类型。

## 2. 执行步骤

1. 花 `5` 分钟手推 `[-4, -2, -9]`，写下每读一个数后的当前最大值。
2. 花 `15` 分钟在 `demos/day-01-max.mjs` 中实现函数。不使用排序、展开参数或现成求最大值函数。
3. 花 `10` 分钟添加断言并运行，输出覆盖的用例和通过结果。运行约定见[练习说明](../demos/README.md)。
4. 花 `5` 分钟解释循环中一直成立的事实，以及时间、辅助空间成本。
5. 填写下面的实际记录；还有时间再尝试返回最大值首次出现的位置。

## 3. 必须验证的用例

| 输入 | 期望返回 | 检查目的 |
| --- | --- | --- |
| `[]` | `null` | 空输入约定 |
| `[7]` | `7` | 单元素 |
| `[-4, -2, -9]` | `-2` | 不能错误地把最大值初始化为零 |
| `[3, 3, 1]` | `3` | 重复最大值 |
| `[1, 5, 2]` | `5` | 最大值在中间 |

另外比较调用前后的数组，确认没有修改输入。断言失败应先保留失败输入和原因，再修正实现。
