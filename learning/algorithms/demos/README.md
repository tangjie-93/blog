# 练习代码

## 1. 第一个练习

由学习者创建 `day-01-max.mjs`，实现第一天约定的 `maxValue(nums)`。不要先复制答案；这里不预置解法或已经通过的结果。

使用仓库现有的 `Node.js` 环境和内置 `node:assert/strict`，不安装测试依赖。在同一文件中写函数和断言，覆盖当天列出的用例，并确认输入未被修改。

## 2. 运行方式

创建文件并完成实现后，在仓库根目录运行：

```sh
node learning/algorithms/demos/day-01-max.mjs
```

第二个练习可命名为 `week-01-move-zeroes.mjs`，按相同方式运行。断言全部通过后打印一条成功信息；失败时保留输入、期望和实际结果。

这些文件是独立练习，不会由博客测试自动执行。每次在学习记录中写下实际运行的命令和结果。

## 3. 验证习惯

先明确题目契约，再选择用例。对于链表和树，可用自己构造的小结构验证；不为了做一道题搭建通用算法库。未来代码复杂后再按实际需求拆分测试。
