# 阶段里程碑

## 1. 长期目标

以[十六周路线](../../docs/articles/算法/算法学习路线.md)为主线，用约 `4～6` 个月逐步建立独立解题能力；实际进度随验收调整。

| 阶段 | 学习周 | 可检查的结果 |
| --- | --- | --- |
| 线性基础 | `01～04` | 能用扫描、计数、指针或前缀和解决小问题，并说出适用约束 |
| 结构与递归 | `05～08` | 能画链表变化、维护二分区间、解释递归契约与树遍历 |
| 搜索与策略 | `09～12` | 能正确处理访问状态、堆性质、回溯撤销和贪心理由 |
| 动态规划与迁移 | `13～16` | 能推导状态及顺序，并在不提示分类的情况下尝试混合题 |

## 2. 最近两周

第一周：数组扫描、移动零、测试与复杂度。第二周：哈希计数，将重复查询改为保存已知信息。第一周未通过时先补扫描，不急着进入哈希。

每阶段结束时选一道代表题闭卷重做，并改变一个约束检查方法是否仍成立。没有通过就延长阶段，不增加新题弥补。

## 3. 今天的最小闭环

[独立写最大值扫描](./daily/day-01.md) → 运行至少 `5` 个断言 → 用自己的话解释当前最大值的含义 → 记录实际卡点。

只完成阅读时记为“尚未验证”，不记为通过。
