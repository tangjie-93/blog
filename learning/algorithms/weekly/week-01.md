# 第一周：会扫描、会验证、会解释

## 1. 本周目标

确定真实起点；能独立扫描数组、维护简单状态、处理边界，并解释一次遍历的成本。只安排一个自拟题和一道平台题。

| 学习次数 | 任务 | 最低产出 |
| --- | --- | --- |
| 第一次 | [第一天：最大值扫描](../daily/day-01.md) | 一个函数、至少 `5` 个断言、复杂度说明 |
| 第二次 | 关闭旧代码重写扫描；尝试[移动零](https://leetcode.cn/problems/move-zeroes/) | 手推一个例子，先写自己的方法，说明是否原地 |
| 第三次 | 实现或修正移动零，测试全零、无零、交替零和单元素 | 一份可运行代码；说明如何保持顺序 |
| 第四次 | 距首次练习至少 `3` 天后闭卷重写最大值；复述移动零 | 重做结果和[周复盘](../reviews/week-01-review.md) |

其余时间休息或轻量回忆。可将本周拉长到两个自然周。

## 2. 阅读范围

只读[基础文章](../../../docs/articles/算法/数据结构和算法基础知识总结.md)的复杂度和线性结构相关部分。独立尝试移动零后，可读[双指针教程](../../../docs/articles/算法/双指针与滑动窗口.md)第三节核对不变量，暂不要求阅读滑窗部分；遇到不确定结论参考学习路线中的教材。暂不阅读排序大全、树专题长文和动态规划。

## 3. 验收与调整

- 最大值扫描能独立实现，并覆盖空数组、负数、重复最大值和单元素。
- 移动零能手推，说明是否保持非零元素顺序、是否修改输入。
- 能解释两段实现的循环次数和额外空间，保留运行结果。
- 间隔重写没有依赖答案；需要提示的部分如实记录。

通过后进入哈希计数；扫描仍有困难，就多用一次学习做找最小值和计数。移动零困难时先用纸笔标出已处理区间，不强迫同时学习更多双指针题。
