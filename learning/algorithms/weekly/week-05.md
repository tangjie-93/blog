# 第 5 周：链表、栈与队列

## 1. 目标与先修

先修：引用与循环。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/leetcode之链表专题.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 画出前驱、当前和后继，独立反转链表 | 手推记录和自己的初版 |
| 第二次 | 阅读栈与队列文章并实现括号匹配 | 可运行代码和边界断言 |
| 第三次 | 选做快慢指针检测环，构造无环与入环样例 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷重写反转链表，手推队列和栈的不同访问顺序 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

空链表与单节点正确；反转不丢节点；括号类型与顺序都正确。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：先改 next 再读后继，或者括号只统计数量。
