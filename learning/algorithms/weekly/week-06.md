# 第 6 周：二分与插入排序

## 1. 目标与先修

先修：有序数组与循环不变量。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/算法之查找.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 闭区间二分，手推单元素和最后候选位置 | 手推记录和自己的初版 |
| 第二次 | 实现第一个不小于目标的位置，覆盖重复值 | 可运行代码和边界断言 |
| 第三次 | 选做排序文章中的插入排序，解释有序前缀 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷重写二分，用直接扫描对照小输入 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

每次循环严格缩小候选区间，区分匹配下标和插入位置。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：循环跳过最后位置，或混合两套区间约定。

- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
