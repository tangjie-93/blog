# 第 7 周：递归与分治

## 1. 目标与先修

先修：函数参数、返回值与数组区间。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/leetcode之递归专题.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 写出后缀求和的契约、终止条件和缩小过程 | 手推记录和自己的初版 |
| 第二次 | 逐层手推调用和返回，改写成循环并比较空间 | 可运行代码和边界断言 |
| 第三次 | 阅读分治与排序文章，独立实现归并的合并步骤 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷重写后缀求和或归并，记录递归栈成本 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

能从子问题契约推导当前层，并解释为何会终止。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：漏 return、每层复制数组却忽略成本、递归没有缩小。

- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
