# 第 8 周：二叉树

## 1. 目标与先修

先修：递归契约与栈队列。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/数据结构之树.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 根据结构画前中后序，写最大深度 | 手推记录和自己的初版 |
| 第二次 | 实现分层遍历，用不对称树测试层界 | 可运行代码和边界断言 |
| 第三次 | 选做验证二叉搜索树，构造局部合法但全局非法的反例 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷重写一种树题，比较节点计数与深度的返回值 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

能区分节点值与节点身份，解释高度决定递归空间。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：只比较父子值验证整棵搜索树，或把队列当栈。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
