# 第 9 周：网格与图遍历

## 1. 目标与先修

先修：树遍历与访问标记。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/数据结构之图.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 构建含环和孤立点的邻接表，手推 DFS 与 BFS | 手推记录和自己的初版 |
| 第二次 | 阅读网格专题，独立实现岛屿计数 | 可运行代码和边界断言 |
| 第三次 | 选做图像渲染或被围绕区域，明确是否修改输入 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 重做一种遍历，解释为何入队时标记；拓扑排序作为选学 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

能处理空图、环、不连通与网格边界，说明访问集合的含义。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：出队才标记造成重复工作，或误认为图一定连通。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
