# 第 11 周：回溯

## 1. 目标与先修

先修：递归与共享引用。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/算法基本思想之回溯算法.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 画子集的决策树，再实现选与不选 | 手推记录和自己的初版 |
| 第二次 | 实现不含重复输入的全排列，说明使用标记 | 可运行代码和边界断言 |
| 第三次 | 改变输入含重复值，先思考去重规则；皇后题只选读 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷重写一个搜索，测试返回结果之间不会共享可变路径 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

选择、递归、撤销成对，正确复制结果，解释输出成本。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：忘记撤销，或把同一个路径引用反复加入结果。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
