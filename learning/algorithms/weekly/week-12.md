# 第 12 周：贪心

## 1. 目标与先修

先修：排序与反例思维。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/算法基本思想之贪心算法.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 手推分发饼干，解释为何先满足较小需求 | 手推记录和自己的初版 |
| 第二次 | 按结束时间选择区间，给出交换论证 | 可运行代码和边界断言 |
| 第三次 | 构造贪心找零反例，比较分数背包与零一背包 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷重做一个贪心题；对一个错误策略给反例 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

说明策略的适用条件，能解释为什么局部选择不损失最优解。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：把碰巧通过样例当证明，或把允许拆分的结论用于不可拆物品。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
