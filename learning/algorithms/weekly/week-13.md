# 第 13 周：动态规划入门

## 1. 目标与先修

先修：递归与重复子问题。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/算法基本思想之动态规划.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 画爬楼梯递归树，标出相同状态 | 手推记录和自己的初版 |
| 第二次 | 给递归加记忆化，再按依赖顺序写状态表 | 可运行代码和边界断言 |
| 第三次 | 实现打家劫舍，解释选与不选及初始化 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷推导一题，先写状态定义再写代码 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

每个状态语义唯一，初始化和转移都符合语义。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：先背公式再补状态，或无条件把状态初值设成零。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
