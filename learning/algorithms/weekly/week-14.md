# 第 14 周：网格与序列动态规划

## 1. 目标与先修

先修：状态定义与依赖顺序。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/leetcode之数组连续递增序列题目总结.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 结合动态规划主文实现不同路径，手算小网格 | 手推记录和自己的初版 |
| 第二次 | 实现最长连续递增长度，再比较非连续子序列 | 可运行代码和边界断言 |
| 第三次 | 选做最长递增子序列长度，先用二次时间转移 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷解释以当前位置结尾和前缀最优的区别 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

连续与非连续题不混淆，空输入与相等值都按严格递增处理。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：把前缀最优误当成必须以当前位置结尾。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
