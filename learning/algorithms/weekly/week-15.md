# 第 15 周：背包

## 1. 目标与先修

先修：动态规划状态与初始化。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/动态规划之背包问题总结.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 手推零一背包二维状态，明确容量是不超过还是恰好 | 手推记录和自己的初版 |
| 第二次 | 写一维零一背包，解释容量倒序保证每件只用一次 | 可运行代码和边界断言 |
| 第三次 | 实现零钱兑换，区分无限使用、最少个数和方案计数 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 闭卷对照两种背包循环方向，并构造错误方向的反例 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

不可达状态、零容量和无解返回明确，不能靠背循环模板。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：把零钱兑换归入零一背包，或混淆组合数与排列数。

- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
