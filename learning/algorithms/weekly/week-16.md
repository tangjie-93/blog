# 第 16 周：混合练习与工程迁移

## 1. 目标与先修

先修：前十五周代表题通过验收。未能闭卷完成先修代表题时先补课，不以自然周催进度。

阅读：[本周主文](../../../docs/articles/算法/算法学习路线.md)。每次先尝试，再按需看实现。每周 `4` 次、每次 `30～45` 分钟，选做内容可以跳过。

## 2. 四次学习

| 次数 | 任务 | 最低证据 |
| --- | --- | --- |
| 第一次 | 隐藏分类，选一道旧基础题和一道未做过的变式独立分析 | 手推记录和自己的初版 |
| 第二次 | 补齐这两题的测试与解释，记录是否用了提示 | 可运行代码和边界断言 |
| 第三次 | 自拟菜单树检索：返回匹配 id 的路径，无匹配返回 null，输入为无环无共享节点的森林 | 一种变式或一个反例；选做遇阻则巩固前题 |
| 第四次 | 用同一标准对比第一周与当前证据，选出下一阶段两个薄弱点 | 间隔重做结果与周复盘 |

不要为了完成表格连续抄写答案。每周最多新增 `2～3` 道题，复习挤占时间时主动减少新题。

## 3. 过关标准

菜单支持空森林、多个根及深层节点，不修改输入；能解释遍历成本与深度限制。至少给出 `3` 类相关边界，并记录实际运行结果；其中一道代表题间隔至少 `3` 天重做不依赖答案。

主要误区：只记题量不看迁移，或宣称完成计划就已掌握全部算法。

## 4. 周复盘与调整

- 实际日期、次数与用时：待学习后填写。
- 代码路径、运行命令和输出：待填写。
- 独立 / 提示后 / 题解后 / 未完成：待选择并说明。
- 最小失败用例、根因和修正：待填写。
- 间隔重做日期和结果：待填写。
- 验收结论：待验收，可选通过 / 需要补课 / 重新练习。
- 下周调整：待根据证据决定；没有通过就继续本主题。
